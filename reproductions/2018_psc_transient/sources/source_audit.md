## 1. 首先冻结的结论与证据等级

- **原文明示**：单变流器、无限大母线；交流电压控制保持 PCC 电压幅值；恒定直流电压；线路只保留电感；忽略电压内环动态；只研究没有触发过流限制的扰动。限流阈值报告为 1.8 p.u.（pp.4–5，III-A；文本行351–432）。
- **原文明示**：正常 PSC 由功率误差积分生成相角；限流触发时改为 PLL 同步的矢量电流控制。Fig.4 是后一分支的说明，正文明确将其暂态分析排除在本文范围外（p.4 Fig.4，p.7 Table II）。
- **原文明示**：Table I 的标幺参数、正文角度 26.4°/60.5°、CCA=108°、CCT=0.58 s，以及清除延时 0.5/0.7 s。
- **图轴推断**：Fig.9/10 绘图窗口约为 2–7 s，扰动发生在 3 s。据此，0.5/0.7 s 是故障持续时间，对应绝对清除时刻 3.5/3.7 s。正文并未给出完整仿真输入文件或采样时间表。

## 2. 拓扑与状态变量

### 2.1 正常系统与 Type-I

Fig.3（p.4）从左至右：变流器输出滤波电抗 Xf → PCC → 公共电抗 XT → 两条并联线路 Xg1、Xg2 → 无限大母线。**Xf 位于被调压的 PCC 上游，不应再加到 Eq.(2) 的 PCC–grid 传输电抗中。**

正常 Xpre = XT + (Xg1 || Xg2)。Type-I 断开线路2，故障后 Xpost = XT + Xg1。原文称对称三相开路扰动（III-C，p.6；文本行584–591）。保持 Pref、Vmref 不变，不添加虚构的重合闸动作。

δ = θref − θg 是 PCC 电压相角相对无限大母线相角；并非变流器滤波器前电势相角。Eq.(5)：

```
dδ/dt = Ki [Pref − (3/2) Vmref Vg sin(δ)/Xg]
a = Ki Pref
b = Ki (3/2) Vmref Vg / Xg
dδ/dt = a − b sin(δ)
```

t 为秒，Ki 使用与实际瓦特配套的 SI 增益时，不应额外乘一次基频。标幺功率写法为 dδ/dt = (Ki Pref_base) (pref_pu − pe_pu)。

### 2.2 Type-II 故障及清除

Fig.1（p.3）画出线路2入口侧的接地支路 Xgnd，连接点位于 XT 之后、Xg2 之前且在断路器 S3 的线路一侧；未给线路中点百分比。III-D 指定使用与 Fig.2(b) 相同的高阻抗三相对地故障；正常及故障中两条线路仍连接，故障通过打开线路2两端 S3、S4 清除（II-B 文本行261–268、III-D 行658–664）。

因此，不能将“清故障”实现成仅移除接地支路、同时保留线路2。后者恢复的是故障前拓扑，与本文 post-fault 曲线不同。

由该拓扑独立推导，记 Xp = Xg1 || Xg2：

```
Xpre = XT + Xp
Xpost = XT + Xg1
Vth_fault = Vg * Xgnd / (Xgnd + Xp)
Xth_fault = XT + (Xgnd || Xp)
Xfault_transfer = XT + Xp + XT*Xp/Xgnd
P_fault = (3/2) Vmref*Vg / Xfault_transfer * sin(δ)
```

**Xfault_transfer 仅等价于有功传输系数所用的电抗。** 若计算电流，必须使用 Vth_fault、Xth_fault，不能错误地把原 Vg 与 Xfault_transfer 拼成一段串联支路。

## 4. 220 kV、标幺列与正文目标的交叉核验

以下仅作代数和 Eq.(12) 等价一维定积分核验，**没有运行时域轨迹仿真**。

将 1000 MW 视为总三相有功基准，f=50 Hz：

| 对 220 kV 的解释 | 对应阻抗基准 Ω | SI Type-I 初始角 | SI Type-I 故障后角 | 与原文的关系 |
|---|---:|---:|---:|---|
| 相电压 RMS | 145.2 | 26.330249° | 59.934418° | 与标幺电感/角度接近，差异可由表列舍入产生 |
| 相电压峰值 | 72.6 | 62.509680° | 无平衡点 | 无法对应 Fig.9 |
| 线电压 RMS | 48.4 | 无平衡点 | 无平衡点 | 无法对应 Fig.9 |

因此，相 RMS 是目前最一致的解释，**仍须保留“推断”标签**。对应 Eq.(2) 取峰值 Vmref=Vg=√2×220 kV，或等价写成 RMS 公式 P=3 Vphase_rms² sinδ/X。

Table I 标幺 Type-I 给出 Xpre=0.445、Xpost=0.87：
- asin(0.445)=26.423339°，asin(0.87)=60.458639°。
- 四舍五入即正文 26.4°、60.5°（p.7 IV-A-1；文本行816）。
- 故障瞬间 δ 连续，简化模型有功从1降到0.445/0.87≈0.51149 p.u.，随后单调恢复；这是可审计的模型推论，不是数字化原始波形。

Table I 标幺 Type-II：
- Xpre=0.9263157895，Xpost=0.95，Xfault_transfer=1.1284210526。
- 初始稳定角67.867609°；故障后稳定角71.805128°；CCA=180°−71.805128°=108.194872°。
- a=Ki×10⁹ W=9.3 s⁻¹，b_fault=8.241604478 s⁻¹。
- ∫[δ0→CCA] dδ/(a−b_fault sinδ)=0.580269817 s，吻合原文108°、0.58 s。
- 用未调整的 SI 电感及相 RMS 解释，得到 CCA=107.824653°、CCT=0.558671573 s。差异应报告为参数精度/基准敏感性，不通过调 Ki、Lgnd 或电压来“修复”。

**Ki 的另一个未说明基准**：若按常见 ωbase=2π50、总三相 Pbase=10⁹ W 定义，Ki_pu=Ki_SI×Pbase/ωbase=0.029602819，而表中为0.01。文中没有足够的基准定义消除该差异。主分支采用明确的 SI Ki，使 a=9.3/s；不能直接将0.01乘ωbase并仍声称复现原文0.58 s。

## 6. 假设、缺资料与可检验问题

1. **详细控制与 EMT**：IV开头说仿真/实验包含电压内环与过流限制，本文未给出这些模块的完整增益、采样/开关频率、延迟、调制器、限流检测与切换参数。Fig.3/4 框图不能替代完整模型。只复现 Eq.(5) 不应标为完整 EMT 或实验波形复现。
2. **限流边界**：1.8 p.u. 是明示数值，但电流基准、RMS/峰值口径、检测滤波与复归规则未写明。按常规三相基准，post-fault X=0.95时，约化相量电流在δ=π为2/0.95≈2.105 p.u.；发生整圈滑移会经过该位置。这提示晚清除情形与“未触发限流”之间需进一步核验，不能据此直接判论文错误，也不能把标量模型成功当成带限流装置成功。当前范围必须注明“不验证限流未触发”。
3. **再同步不等于重合闸**：本文清故障是打开线路2断路器；恢复后仍为单线路。没有重新合闸时刻、残余电压、重合相角检测或再次冲击条件。任何重合闸测试都是新扩展。
4. **CCA与CCT**：给定post-fault参数时，CCA由Eq.(11)确定；CCT还依赖故障中a、b及初始角，见Eq.(12)。不能把“固定CCT”推广成对所有故障深度/增益不变。
5. **解析解分支**：Eq.(9)/(10)/(12)写出的实数arctan形式含√(a²−b²)，直接适用本例a>b的无平衡点故障阶段。有平衡点的Type-I有a<b，需另一实数积分形式或直接ODE；跨π时还须处理反正切分支。不能不作分支判断地把同一表达式套在所有场景。
6. **临界等号**：在理想标量系统中正好位于post-fault不稳定平衡点时，导数为零；数值误差会决定偏向哪边。分类应把δclear=CCA视为临界边界，不通过积分器误差生成必然成功/失败结论。
7. **硬件基准**：Table III为另一组舍入SI参数，正文声称标幺等效，不能把该表替换Table I后声称完全相同。实验测得相角使用PLL并不表示正常PSC控制回路由PLL同步；检测与控制两者应分开。
8. **缺少原始数据**：已检稿件不提供原始仿真轨迹、模型文件、控制代码、逐样本实验波形及误差定义。因此当前可以比较解析目标与约化模型结构，不能提出未经声明的逐点实验波形通过阈值。
