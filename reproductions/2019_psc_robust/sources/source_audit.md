## 1. 可以开展的计算性复现

优先复现完整小信号传递函数Eq.(9)–(12)、Fig.5的PSC与直流侧Nyquist、Fig.7/8的VSM比较，并把有限高通带宽与冻结高通近似分开。可直接验证增益选择、平衡点、极点、交越频率、增益/相位裕度及高无功下的带宽下降。所有裕度仍需先检查闭环稳定性与适用工作点。

Fig.11–17属于硬件实验。连续平均模型或小信号曲线只能验证其中部分机制，不能据此称实验波形已逐点复现。原始实验轨迹、控制工程文件、传感器与完整限流逻辑未随本文提供。

本文的三个不同层次不得混用：

1. **完整小信号模型**：有限ωb，Ha(s)=Ra s/(s+ωb)，Eq.(9)/(12)。
2. **冻结高通近似**：ωb可忽略，Ha(s)=Ra，Eq.(14)，也是两个增益裕度定理的声明条件。
3. **进一步近似因式分解**：Eq.(15)，要求|a|、|b|很小。由它推出的主导极点、阻尼和带宽不是所有工况下的精确表达式。

## 2. 模型边界、符号与单位

- **明示，pp.2–3 Section II**：L包含变流器滤波、变压器及电网串联电感；R忽略；电网无限大母线、Vg恒定；SCR从变流器端看，定义为1/L_pu，和从PCC看不同。
- **明示**：V代表变流器电压基准幅值，电压/无功外环若存在则假设足够慢而忽略；PWM延迟与谐波被忽略。
- **明示，Eq.(7)**：电压命令为v=V−Ha(s)i；即使V恒定，瞬态|v|仍可变化。不能把仿真输出电压强制钳在V。
- **明示**：Fig.2含嵌入电流控制器CC，正常时透明，必要时限流；它不是本设计研究对象，文中不再建模。这里没有IEEE2018 transient那篇的“1.8 p.u.”限流参数，不能跨论文移植。
- **明示，Eq.(5)**：κ=3/(2K²)。标幺或功率不变空间矢量K=√(3/2)时κ=1。实验Section V使用峰值空间矢量K=1，因此实际SI功率公式用κ=3/2。
- **明示，Eq.(8)**：P0=κV id0、Q0=−κV iq0。**iq0<0为无功注入，iq0>0为无功吸收**。
- **明示，Appendix I/III**：|θ0|≤π/2，且V−jω1Li0=Vg exp(−jθ0)。给定(V,L,id0,iq0)后，Vg与θ0不能再任意独立设置。
- **复现换算**：τ=ωbase t时，角频率、极点及控制器带宽按ωbase归一化；rad/s转Hz需除2π。物理H=5 s不能未经换算写成标幺时间5。

Eq.(9)按原图完整写为：

```
GθP(s) = κV²/(ω1L)
         × [a s² + (1+a+b(s))ω1²]
         / [s² + 2Ha(s)s/L + ω1² + (Ha(s)/L)²]
```

Ha(jω)²是复数平方，不是|Ha(jω)|²。Eq.(38)的实部操作是建立实系数传递函数的过程，不能在代入s=jω之后简单取响应实部，造成虚部丢失。GθP在a≠0时有直接通道，数值实现不能擅自删去高次分子。

Eq.(14)记α=Ra/L、c=1+a+b：

```
Gc = α[a s²+cω1²]
     / [s³+(2+a)αs²+(ω1²+α²)s+cω1²α]
```

## 4. 高无功极限与“带宽”的准确含义

Eq.(41)给a≥−1，不是无条件允许任何指定电流。需同时满足给定Vg和负荷角支路。给定电流点复算时，可由Eq.(35)推导：

```
Vg = sqrt((V+ω1L iq0)²+(ω1L id0)²)
θ0 = atan2(ω1L id0, V+ω1L iq0)
```

例如Fig.5下排SCR=1、V=1、id0=.2、iq0=−.95，得到a=−.95、Vg≈.206155 p.u.。强行再设Vg=1将不再是该工作点。

- Eq.(21)给该点ωc≈.01 p.u.≈3.14159 rad/s≈0.5Hz，**只是主导极点近似**。此时|a|已接近1，且预测频率比ωb=.1更低，冻结Ha≈Ra尤其不能当作精确频率响应。
- 有限ωb时Ha(0)=0、b(0)=0；冻结Ha=Ra近似下b为非零常数。s→0和ωb→0的极限不可随意互换。
- 低电流、Lmax=1、Ra=.2时Eq.(17)估计ωc,min≈.2 p.u.，即62.83rad/s≈10Hz；Eq.(18)上限估计约50Hz，有明确主导极点条件。
- Eq.(16)/(20)的ζ是近似极点阻尼，不是精确闭环频响峰值或所有情况下的二阶阻尼比。
- Kd是“理想dc-link环带宽”的量纲化增益，不等于存在内环Gc时实际dc闭环−3dB带宽。
- 原文没有统一规定精确的−3dB带宽提取规则。若平台计算−3dB，应预声明DC归一化、多次穿越/谐振处理，并同时报告Eq.(21)近似值。
- Theorem1并未证明所有工况相位裕度≥45°；文中是选取gm目标并用例子检查相位裕度。Fig.5明确承认高无功、SCR=1的dc环相位裕度低，以及有限ωb造成部分gm略低于4。这些不能被报告成新发现的“定理失败”。

## 7. 附录IV：原文与可复算表达式的代数一致性问题

这是对确切作者稿p.10的审计，不是OCR推断，更不是硬件结果造假结论。

原稿印刷：
- 相位交越频率ωπ=ω1√[(1−b)/(2+a)]。
- Eq.(42)：gm=(1/Kd)[(1−b)ω1²L/((2+a)Ra)+Ra/(2L)]。
- 其后称最小值出现在L=√2 Ra/ω1。
- Eq.(43)：gm,min=(ω1/Kd)√[(1−b)/(2+a)]。

由Eq.(14)和Gd=KdGc/s直接整理，在有限非零交越、未发生抵消的常规条件下，可得到：

```
omega_pi² = (1+a+b)/(2+a) * omega1²
gm = 1/Kd * [ (1-b)omega1²*L/(2(2+a)Ra) + Ra/(2L) ]
```

即印刷Eq.(42)第一项相对该推导缺少分母2，且交越频率的分子应由1+a+b得到。上述推导仍需与独立verifier比对；不修改纸面公式来让所有检查“通过”。

**最小且不依赖非零工作点的核验**：

```
omega1=V=kappa=1; i0=0 -> a=b=0
Ra=.2; L=sqrt(2)*.2
Kd=1/(4sqrt(2)); omega_pi=1/sqrt(2)
Eq14直接代入：Gd(j omega_pi)=-.25 + O(1e-17)j
真实该频点gm=4
印刷Eq42：gm=6
印刷Eq43：gm=4
```

因此Eq.(42)与Eq.(14)/(43)存在可隔离的数值不一致。修正后的gm表达式可通过AM-GM得到Eq.(43)形式的下界，因此这一发现**不自动推翻推荐Kd**。将a、b视为独立常数时，修正表达式的驻点为L=(Ra/ω1)√[(2+a)/(1−b)]；原文L=√2 Ra/ω1只在a=b=0时对应。实际扫描L时a、b通常随L改变，更不能直接套通用最小L。

其他使用范围检查：Eq.(40)写作gm≥2时，分母1−(Ra|i0|/V)²的正性不可省略；降压或大电流使分母非正时，应返回完整Nyquist/极点检查，不机械返回“至少2”。这属于推导适用域审核，不能仅凭一个代数负值直接宣称所有实际工作点不稳定。
