# LLC 端口等效与独立核验

`u` 是整流桥两交流端的差模电压，`v_o` 是输出端。取变比 `n=Np/Ns`，一次端电压为 `n u`，二次侧送入整流的有符号电流为 `n(i_r−i_m)`。Fig. 1 的两组对角开关在正、负半周可分别等效为戴维南源 `E=±V_in(g_on−g_off)/(g_on+g_off)` 串联 `R_b=2/(g_on+g_off)`。全桥抽查保留四只一次侧开关、原始两级节点和理想变压器约束。

后向欧拉的串联电感和电容消元得到

```text
gamma = 1 / (L_r/Δt + R_b + Δt/C_r)
i_r = gamma [(L_r/Δt)i_r_old + E − v_Cr_old − n*u]
i_m = i_m_old + Δt*n*u/L_m
h1 = n [gamma ((L_r/Δt)i_r_old + E − v_Cr_old) − i_m_old]
g1 = n²(gamma + Δt/L_m)
h2 = (C_o/Δt)v_o_old
g2 = C_o/Δt + 1/R_L
```

对称桥在四种可行状态下满足 `vx + vy = v_o`。令 `a=g_d1=g_d4`、`b=g_d2=g_d3`、`s=(a+b)/2`、`d=(a−b)/2`，根据两个端口的 KCL 有

```text
[(g1+s)   -d    ] [u  ] = [h1]
[  -d    (g2+s) ] [v_o]   [h2]
```

`v_o ≥ |u|` 时四只二极管关断，`v_o ≤ −|u|` 时四只导通。其余区域按交流极性选对角导通。把二极管极性等式代回二端口得到边界斜率 `m1=(g_off+g2)/(g_off+g1)` 与 `m2=(g_on+g2)/(g_on+g1)`。映射的每个状态用预计算系数推进。合成上一拍状态更新和本拍 Norton 电流映射，直接核对式 (31) 的单级重排。

独立轨迹参考在每个步长组装 `i_r`、`i_m`、`vx`、`vy`、`v_o` 的五元节点方程。仅由每个二极管两端电压决定状态可行性。上一拍状态不满足严格符号时枚举 16 个组合；共享边界允许零电压二极管使用等价值分支。另对启动和稳态换流采样点以带理想变压器的完整开关网络做独立节点求解。

完整网络的一次侧导通阻值与二次侧阻断通路相差多个数量级。首轮直接使用两个交流节点物理电压，阻断时的共模出现约 38 μV 数值误差。两行 KCL 的和、差和共差模变量显式消除了公共的大电流项。首轮检查阈值与电路参数保留。两个实现还用储能差、后向欧拉数值耗散和器件耗散核对每步能量平衡。 首轮清单 · [完整网络代码](../src/network_check.py)
