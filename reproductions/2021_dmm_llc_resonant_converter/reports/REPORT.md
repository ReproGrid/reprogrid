## 整流阻断与波形误差

Set #2 在 312.5 kHz、15 ns 下的阻断占空为 **36.12%**。仅允许两对二极管导通并保留后向欧拉，谐振电流 NRMSE 达 **9.65%**，峰值绝对误差 **3.26 A**。改用原文所述双状态前向欧拉，误差增至 **19.57%** 和 **5.65 A**。两种双状态近似在完整参考处于阻断时都频繁切换导通对，同一 0.1 ms 窗口分别计 **1163** 次和 **1014** 次。

| 参数组及频点 | BE 阻断占比 | 完整 BE 峰值电流 | 双状态 BE 电流 NRMSE | 双状态 FE 电流 NRMSE |
| --- | ---: | ---: | ---: | ---: |
| Set #1，100 kHz 假设 | 38.79% | 31.76 A | 1.64% | 2.76% |
| Set #2，312.5 kHz | 36.12% | 19.58 A | 9.65% | 19.57% |
| Set #2，400 kHz 敏感性 | 22.79% | 12.67 A | 6.94% | 16.26% |

误差以同一离散步长、同一采样时刻的完整后向欧拉 `i_r` 为基准，窗口为 47.9–48.0 ms。Set #1 的 100 kHz 工况更接近两种双状态近似，其中 `m1≈4.21e+07`，Set #2 同步长 `m1≈4.57e+04`，支持原文指出的不同比例下忽略阻断的影响。阻断时间比例同时依赖工况，Set #1 在本频点的比例略高。表 I 的串联谐振频率为 160 和 500 kHz，按表中元件计算分别为 **159.155** 和 **505.828 kHz**。 [阻断电流图](../figures/rectifier_blocking.png) · [仿真协议](../configs/protocol.json)

## 步长与可重复的失稳范围

- Set #2 在 312.5 kHz 下，对各自时钟的 1.875 ns BE 解，7.5、15 和 30 ns 的 `i_r` NRMSE 分别为 **2.83%**、**6.48%** 和 **13.30%**。固定 15 ns 门极采样时刻后，3.75、7.5 和 15 ns 对相同门极时刻的细步长解，误差分别为 **1.07%**、**3.19%** 和 **7.29%**。这组对照量化了积分步长的影响，DMM 的状态选择与同一步长的解法精度见下节。
- 原文描述 Set #2 的 FE 在步长达到 30 ns 时出现不稳定。在本复现检查的 **312.5、400 和 500 kHz**，30 ns 双状态 FE 均跑满 48 ms。312.5 kHz 的电流 NRMSE 已达 **37.81%**，参照 15 ns 的完整 BE。Set #1 在 100 kHz 的 30 ns 双状态 FE 于 **261.96 μs** 触及数值截断，而 15 ns 完整 BE 和双状态 FE 均完成。原文 Fig. 4 的具体门极时序、初态和 FE 工程未找到，这一差异只适用于所跑频点。
- Set #1 在 160 kHz 用零储能启动时，15 ns 完整 BE 在 **37.34 μs** 触及数值截断。输出电容预充到额定 400 V 后，同一设置完成，晚期平均输出为 **396.36 V**。截断属于协议中的数值条件，停止时间和触发量都保留在指标中。 [步长对照](../figures/step_size.png) · [全部工况数据](../results/metrics.json)

## 算法核验与复跑

三个主工况共 **9,600,000** 步逐点核对。DMM 每步先判定状态，再算下一步，独立参考共执行 **12,210,960** 次小节点方程求解。两者的电感电流最大差 **8.52e-08 A**，相关电压状态最大差 **2.28e-06 V**，轨迹中整流状态相同。KCL 最大相对残差 **1.1e-09**，后向欧拉离散能量最大相对残差 **5.29e-10**。四种整流可行区域均用合成见证点核验，普通负荷轨迹访问阻断与正负导通。另用含四只原边开关和理想变压器的完整网络抽查 **167** 步，并逐步核对式 (31) 的单级历史电流映射。

将阻断状态下的共模和差模分开求解后，54 组试验的 **51/51** 项校验全部通过。独立环境重新编译和运行后，图件、数组与指标的文件哈希一致。
