# 第十一篇复现报告 · 虚拟同步发电机的稳定性参数约束

IEEE TPWRS 10.1109/TPWRS.2019.2896853。对一台 10 kV、1 MW VSG 接 50 Hz 电网，复现式 (1)–(8)、三组印刷工况、两种算例 2 参数推断，以及图 2–5 的可读数值。31/31 项内部数值与图形门槛通过，干净环境重跑一致。

## 证据与模型

原稿给出相电压峰值 8.165 kV、零初始相角、物理线路 0.0124 Ω 与 0.1 H、惯量 M=2600。虚拟阻抗按作者假设视为线路的串联等效。电压环用原文三阶传递函数。按滤波电感与电流环比例增益取内环时间常数 0.49215 ms，另外扫描文中 0.5–5 ms 范围。

主实现用原文传递函数和闭环多项式。独立实现从摆动方程、电压环状态、dq 线路 KVL 与物理端口功率构造状态空间。五个分支中闭环极点最大差 3.9e-11 rad/s，频响最大相对差 1.4e-12。积分器在原点处作绕行，Nyquist 绕数与右半平面极点计数一致。PDF 图 2–5 读出 33 条曲线的 4,412 个向量点。

| 算例 2，印刷参数 | 无交越 | 无 | 0.000 | 线性化角度存在零极点 |

**算例 1** 的二阶模型相位裕度为 74.08°，接近文中 74.1°。完整模型为 72.16°。按图 5 算例 1 功率上升位置推断参考阶跃在 0.50 s，0.5 MW 阶跃后平均模型对图中 EMT 曲线的 RMSE 为 0.0259 MW。原曲线在阶跃前已有启动暂态。

**算例 2** 的印刷值 Lv=−0.1 H 与 Lg=0.1 H 相消。零初始相角下，纯电阻支路的线性有功对相角增益为 0，无法得到图 3 的线路共振和 414.2 rad/s 交越。只用 414.2 rad/s 反算，两个正的总电感为 395.988 和 3.934 μH。

较大根对应 Lv=-0.099604012 H，得到增益裕度 -18.069 dB，负实轴交越 288.29 rad/s，接近文中 −18.1 dB 和 286 rad/s。线路 Bode 幅值 RMSE 为 1.11 dB，较小根为 20.22 dB。原模型的未舍入电感仍待核对。

**算例 3** 的印刷条件给出完整模型主导极点实部 -2.023 rad/s，且 6.80° 相位裕度复现了文中 6.8°。二阶闭环的特征式为 M·s²+D·s+H₀，三个系数均为正，极点也在左半平面。正文把这一组 Bode 结果判为不稳定，和按式 (1)–(7) 算出的闭环极点不一致。文中 33 rad/s 还高于 0.1ωg=31.416 rad/s。

图 5 的算例 3 则出现幅度增大的 EMT 振荡，阶跃后两次正峰为 1.393 和 1.848 MW。独立平均模型的振荡衰减，阶跃后 RMSE 为 1.068 MW。缺少原开关模型、初始化及控制时序，目前无法归因这处差异。

固定算例 3 其余参数，完整模型的局部稳定边界在 D≈5541.7，独立 dq 模型在此点的主导极点实部为 -1.6e-14 rad/s。满足式 (8) 的两个裕度设计条件需要 D≥72886.9。在内环时间常数扫描的 147 个满足电压环稳定且带宽大于 100 Hz 的点上，算例 3 仍为小信号稳定。
